# Sudoku Tkinter Application

## Project Overview
This project is a Python Tkinter GUI application that allows the user to interact with a 9x9 Sudoku grid. The user can enter numbers, check if their solution is valid, clear the board, and view help information in a second window.

## Features
- 9x9 Sudoku grid using Tkinter Entry widgets
- At least two windows (main game window and help/about window)
- Multiple buttons with callback functions:
  - Check Solution
  - Clear Board
  - Exit
- Input validation to ensure correct data types (digits 1–9)
- Sudoku rule checking for rows, columns, and 3x3 boxes
- At least two images with alternate text descriptions
- Clear navigation between windows
